# Frontend - Ritmo Constante

## Configuração

1. Instale as dependências:

```bash
npm install
```

## Comandos

```bash
# Executar em desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview do build
npm run preview
```

## Estrutura

- `src/api/` - Clientes da API
- `src/components/` - Componentes React reutilizáveis
- `src/pages/` - Páginas da aplicação
- `src/store/` - Estado global (Zustand)
- `src/App.jsx` - Componente principal
- `src/main.jsx` - Entry point

## Tecnologias

- React 18
- Vite
- React Router DOM
- TailwindCSS
- Chart.js
- Zustand
- Axios
